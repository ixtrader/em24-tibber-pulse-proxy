# Security Policy

Please do not open a public issue for a suspected security vulnerability.

Report it privately to [github@brossmann.eu](mailto:github@brossmann.eu), including the affected version, a description, and reproduction steps where possible. You will receive an acknowledgement as soon as practical.

This project is intended for trusted local networks only. Do not expose its Modbus TCP port or the Tibber Bridge HTTP interface to the internet.
